Search syntax#

The search box does more than match words. Everything below can be combined in one query.

Basics

  • Type any words to match a stop’s name, town, description, amenities, or route. gelato
  • Add words to narrow; each word must match. bakery campground

Fields — field:value

  • community:Hope — exact town (the only exact-match field)
  • community:"Maple Ridge" — quote any value with a space in it
  • name:MEC — stop name
  • type:hostel — subcategory (also subcat:)
  • amenity:wifi — a listed amenity
  • route:Kettle — stops on a named route
  • status:welcoming — accreditation status (also accredited, info)
  • price:$$ — price band
  • owner:"Buy BC" — ownership (also "Buy Canadian", chain)
  • indigenous:owned — Indigenous role

Operators — must be UPPERCASE

  • bakery OR cafe — either (or bakery | cafe)
  • cafe NOT chain — exclude (or -chain)
  • vegan AND patio — both (a space already means AND)
  • (cafe OR bakery) community:Tofino — group with parentheses

Quotes

Quotes hold words together as one value, for a field or a phrase.

  • owner:"Buy BC" — a multi-word field value
  • "bike shop" — an exact phrase in the name or description

Good to know

  • Lowercase or / and / not are treated as plain words, not operators.
  • Every field matches partway, except community:, which is exact. So name:Maple finds “Maple Leaf Inn”, but community:Maple finds nothing unless the town is exactly “Maple”.
  • Mix it all: route:Kettle type:campground -reservation
